# AJ MoneyPro – Native Android Kotlin + Jetpack Compose Project

- **App Name**: AJ MoneyPro
- **Package Name / Application ID**: `com.aj.moneypro`
- **Primary Color**: Deep Navy Blue (`#0F172A` / `#172554`)
- **Accent Colors**: Royal Blue (`#2563EB`) and Emerald Green (`#10B981`)
- **Default Currency**: PKR (`Rs.`)

## Build APK in Android Studio
1. Open this folder in Android Studio.
2. Let Gradle sync finish.
3. Click **Build -> Build Bundle(s) / APK(s) -> Build APK(s)**, or run `./gradlew assembleDebug` in Terminal.
